## Half-Aunt vs. Half-Nephew

```ascii
            ДІДО
              │
        СПІЛЬНИЙ ТАТО
          /        \
  НАПІВ-БРАТ    НАПІВ-СЕСТРА
       │              │
     ДИТИНА          ДИТИНА
```

`≈ 1,754 cM` => `984 - 2,462 cM` - СПІЛЬНИЙ ТАТО → ДІД

`≈ 871 cM` => `492 - 1,315 cM` - НАПІВ-БРАТ / НАПІВ-СЕСТРА → НАПІВ-ДЯДЬКО / НАПІВ-ТІТКА
